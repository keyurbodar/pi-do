Baseline facts

  • packages/pi-cf is the Pi agent harness plus our own Durable Object store. No Cloudflare Agents SDK anywhere. Dependencies prove it.
  • Nothing we built duplicates a Cloudflare baseline. The only Cloudflare import in the worker is the git client. Shell backends were tried and explicitly rejected.
  • So section A judges our extras against Pi, not against Cloudflare. There is nothing to delete for duplication.
